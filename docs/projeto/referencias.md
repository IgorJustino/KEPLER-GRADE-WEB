## Origem conceitual

- [Template Fluxo Eng. Software](https://grass-quarter-2f5.notion.site/Template-Fluxo-Eng-software-57a10a8a5f66497ea3bcf160e5d9bcaf), de João Gabriel de Matos.

O template é inspiração para o modelo de acompanhamento acadêmico. Textos, imagens e bases externas só devem ser incorporados após verificação de licença e permissão.

As referências acadêmicas orientam a profundidade e a organização dos artefatos. A modelagem, os requisitos, diagramas e decisões desta documentação descrevem o domínio específico do KEPLER.
